## Fonts

Both are free on Google Fonts. Canva has both in its font list — search the name
and set them as your Brand Kit fonts.

| Role | Font | Weights used |
|---|---|---|
| **Headings, logo wordmark, big numbers** | **Source Serif 4** | 600 (SemiBold) |
| **Body, buttons, labels, nav** | **Instrument Sans** | 400, 500, 600, 700 |
| Data/methodology captions (report only) | IBM Plex Mono | 400, 500 |

- Google Fonts: [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4) ·
  [Instrument Sans](https://fonts.google.com/specimen/Instrument+Sans) ·
  [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono)
- If Canva is missing one, download the TTF from the link and upload it
  (Brand Kit → Fonts → Upload a font).
- Headings use tight letter-spacing (about −2%). In Canva, set letter spacing to
  roughly −20 on large headings.

## Logo files

All PNGs, transparent where noted, sized for print and large-format use.

| File | What it is | Use when |
|---|---|---|
| `campustakes-lockup-navy.png` | Mark + wordmark, horizontal, transparent | **Default logo.** Light backgrounds. |
| `campustakes-lockup-white.png` | Same, white, transparent | On navy or any dark background or photo. |
| `campustakes-mark-navy.png` | Mark only, transparent | Tight spaces, watermarks, when the name is already on screen. |
| `campustakes-mark-white.png` | Mark only, white, transparent | Same, on dark. |
| `campustakes-icon-navy.png` | 1024×1024, navy square, white mark | Social profile pictures, app icons, avatars. |
| `campustakes-icon-white.png` | 1024×1024, white square, navy mark | Profile pictures on dark platforms. |

### Rules

- **Clear space:** leave at least the height of one speech bubble on all sides.
- **Minimum size:** the lockup should never be smaller than about 120px wide on
  screen or 1 inch in print. Below that, use the mark on its own.
- **Never** stretch it, rotate it, add a drop shadow or outline, recolor it to
  anything but navy or white, put the navy version on a dark background, or
  rebuild the wordmark in a different font.
- The mark's aspect ratio is **1.23 : 1** (wider than tall). Lock the ratio when
  resizing in Canva.

## Voice, in one line each

- **Plain-spoken.** Say the thing. No "elevate," "seamless," or "unleash."
- **Numbers carry the argument.** Cite the count, not just the percentage.
- **Claim only what has happened.** Describe what you do; don't promise how well
  it works until it has worked.
- **No em dashes.** Use a comma, a colon, or a full stop.

### One limitation worth knowing

These are high-resolution PNGs, not vector SVGs. They are sharp well beyond any
normal use, including large print. But if you ever need a true vector logo, for
signage, embroidery, or a very large banner, that requires tracing the mark into
an SVG. Ask and I can look into it.
